# Koustav Kayal — Portfolio

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript. Open `index.html` in a browser or serve this folder with any static web server.

## Personalize the portrait

The hero uses `assets/koustav-kayal.jpg` as its portrait. Replace that file to change the photo. If it is missing, the page displays an explicitly labeled placeholder. A well-lit vertical image around 520 × 620 pixels works best.

## Contact form

The form validates its fields in the browser and prepares an email to `kayalkoustav9@gmail.com` using the visitor’s default mail app. The visitor reviews and sends the message from that app; this site does not transmit or store form data. For direct website submissions, connect the form to a server endpoint or a form service and update the submit handler in `script.js`.

## Content edits

Personal details and portfolio content live in `index.html`. Colors, typography, and responsive layouts are defined in `styles.css`. The mobile navigation, portrait fallback, contact-form email draft, and subtle section reveals are in `script.js`.
